# 242. Valid Anagram

- **難易度**: Easy

## 問題概要

2つの文字列 `s` と `t` が与えられる。
`t` が `s` のアナグラムであれば `true`、そうでなければ `false` を返せ。

アナグラム = 文字の並び替えで同じになる（使う文字の種類と数が同じ）

### 例

```
Input: s = "anagram", t = "nagaram"
Output: true

Input: s = "rat", t = "car"
Output: false
```

### 制約

- 1 <= s.length, t.length <= 5 * 10^4
- `s` と `t` は小文字の英字のみ
